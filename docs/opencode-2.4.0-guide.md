# OpenCode 2.4.0 使用指南

以下以 Windows 桌面版为主，另附终端主题设置。版本变化见 [官方 2.4.0 更新日志](https://opencode.ai/changelog/v2.4.0)。

## 1. 内置浏览器：从只读任务开始

1. 在桌面端命令面板搜索 **Open browser**，打开浏览器面板，在地址栏输入网址。想让会话中的网页链接也在此打开，可在 **设置 → Browser** 启用 **Open links in OpenCode**。
2. 需要复用登录时，在 **Browser → Import from another browser** 选择来源浏览器和需要导入的网站。官方支持从 Chrome、Edge、Firefox 或 Safari 导入登录状态与历史。也可以直接在 OpenCode 浏览器里登录；不必导入全部站点。标签页在重启后会恢复。
3. 如果需要扩展，在 **Browser → Extensions → Add an extension** 操作。官方支持从 Chromium 浏览器导入，或从 Chrome / Edge 扩展商店添加；并非每个扩展都兼容。
4. 在会话里发一个只读任务，例如：`打开 https://example.com，告诉我页面主标题，不填写表单。` 在浏览器、文件预览或 Diff 里留下评论后，也可以按 `Ctrl+Enter` 直接交给会话；会按跟进设置发送、引导当前任务或排队。

**注意登录状态。** 如果开启共享远程服务器登录状态，受信任的远程服务器也可能访问已登录站点。不需要就不要打开。不要让网页内容替你授权提交、付款或修改账号。[官方浏览器工具说明](https://opencode.ai/docs/tools/#browser)

## 2. 自动化：先试一次，再做周期任务

在项目会话中告诉 AI **何时运行、在哪个项目、要做什么、结果放哪里**。例如：

> 创建一个只运行一次的自动化：十分钟后在当前项目读取 README，回到当前会话总结三条待补文档。只读，不修改文件；创建后告诉我下次执行时间。

输入 `/automation` 打开管理入口，核对任务与触发时间。验证运行结果后，再改成诸如「每周一北京时间 09:30」的周期任务。官方支持一次性定时、固定间隔、Cron 和已连接 MCP 服务器推送的事件；MCP 触发必须由该服务器实际提供。动作可以是提示词、Code Mode 脚本或固定 Shell 命令。固定 Shell 命令在创建时请求批准，并记录每次退出码和输出；第一次建议用只读动作。若不使用自动化，可在 OpenCode 配置中设顶层 `"automations": false`。

## 3. 生成视频：聊天模型负责发起，视频模型负责渲染

1. 先连接一个提供视频模型的供应商。能聊天不等于能渲染视频；连接完成前若看不到工具，先确认供应商与模型可用。
2. 在项目会话里描述内容、画幅、时长和保存位置，例如：`用 generate_video 做一段约 5 秒的 16:9 产品演示背景，深色桌面上手机缓慢旋转，无字幕；保存到当前工作区。若模型不支持这些参数，先告诉我。`
3. 渲染在后台进行，不必让对话停在这里。任务完成后会报告保存路径；按路径打开文件。视频生成可能产生费用，先试短片。

图片工具由 `experimental_image_generate` 改名为 `generate_image`。旧权限规则会映射，但此前保存的「始终允许」不会迁移，首次仍可能询问。

## 4. 官方 `/goal`：把一个明确目标留在当前会话里

- `/goal 补齐登录表单回归测试，跑测试并汇报结果`：设置目标并开始工作。最好明确完成条件与不应修改的范围。
- `/goal pause`：暂停目标；`/goal resume`：继续暂停的目标；`/goal clear`：清除目标。桌面状态胶囊也会显示跟随中、已暂停或已完成。
- **与自动化的区别**：`/goal` 用于同一会话里持续完成一件事；`/automation` 决定何时启动一个任务。升级后的官方目标不读取旧 Mod 插件的目标数据，也不要把旧 Mod 的 `/goal budget` 或专用输入模式当成官方功能。仍需继续的旧目标请在确认状态后重新设置。

## 5. 桌面操作和 Windows 提示

| 需求 | 操作 |
| --- | --- |
| 归档打开的会话 | `Ctrl+Shift+S`；macOS 为 `Cmd+Shift+S` |
| 在对话中找文字 | `Ctrl+F`（macOS 为 `Cmd+F`），输入关键词，再按搜索栏的上一项或下一项按钮 |
| 让代码块自动换行 | **设置 → 通用 → 时间轴 → Wrap code blocks**；只改一块可用代码块上的 **Wrap lines** |
| 切换会话但保持侧面板打开 | **设置 → 通用 → Keep side panel open across sessions** |
| 设置两段快捷键 | **设置 → 快捷键**，录入第一段后点 **+** 添加下一段，最多四段；如 `Ctrl+K` 后按 `Ctrl+C`，设置前先检查冲突 |
| 看任务是否需要你 | Windows 任务栏图标显示进度与待处理数，权限或提问等待时会闪烁；右键图标可选 **New Session** 或 **New Window** |
| 找没发送的草稿 | 使用官方 Inbox 布局时，查看侧栏 **Drafts** 组；Mod 的 Codex 侧栏并非官方 Inbox 界面 |

## 6. 终端主题、插件和升级排查

- **TUI 新主题**：默认是新版 `opencode`。要恢复旧配色，输入 `/themes` 选 `opencode-classic`，或按 `Ctrl+P` → **Open settings → Theme**。这只调整终端界面，不调整桌面。[官方主题说明](https://opencode.ai/docs/cli/theme/)
- **插件更新**：在 **设置 → 扩展 → 插件** 检查更新，或用 `opencode plugin check`。仅 `@latest`、版本范围、Git 分支等跟踪型引用会在启动时及每 24 小时自动检查并更新；普通包名不自动跟进，精确版本与提交哈希固定。Mod 改的是桌面安装包，不由插件自动更新管理。[官方插件说明](https://opencode.ai/docs/plugins/)
- **Copilot 登录**：如果之前只依赖 `GITHUB_TOKEN`，改用 OAuth 登录或设置 `COPILOT_GITHUB_TOKEN`。ChatGPT 登录的模型列表则改由 models.dev 提供。
- **远程服务器**：新版桌面原生语音需要匹配版本的服务器。插件也改为后台加载，刚连接时模型或工具列表可能短暂不全；等加载后再重试，不要因此马上重配账户。
