# 本地文件快捷操作

## 使用

完全退出 OpenCode Desktop，然后运行仓库的 `应用桌面端补丁.cmd`（或 `node apply-mod.mjs`），再打开客户端。安装日志出现「文件快捷操作：点击打开…」说明已启用。还原官方 ASAR 会一并移除本功能，不修改会话数据和文件关联。

在**已识别的对话文件链接**上操作：

| 操作 | 效果 |
| --- | --- |
| 点击 / 聚焦链接后 Enter | 使用系统默认应用打开；Windows `.ps1/.bat/.cmd` 改用系统记事本查看 |
| 右键 / 链接聚焦后 Shift+F10 | 打开系统原生文件操作菜单 |
| 打开所在文件夹 | 打开资源管理器并选中文件 |
| 复制完整路径 | 复制本地绝对路径；文件已不存在时也可复制解析后的路径 |
| 在所在目录打开终端（Windows） | 打开可见 PowerShell 窗口，工作目录设为文件所在目录；文件夹则进入该文件夹 |
| 使用 PowerShell 运行…（Windows `.ps1`） | 确认后在可见 PowerShell 窗口运行，窗口保留以查看输出 |
| 使用命令提示符运行…（Windows `.bat/.cmd`） | 确认后在可见 CMD 窗口运行，窗口保留以查看输出 |

优先使用标准安装位置的 PowerShell 7，否则使用 Windows PowerShell。不在工作区或任意 PATH 中搜寻解释器，不执行自定义命令模板。

运行确认显示完整脚本路径、工作目录及实际解释器。默认取消；不请求管理员权限、不修改执行策略、不添加 `ExecutionPolicy Bypass`。被策略拦截时保留 PowerShell 原始报错，不自行重试或绕过。其他可能执行内容的文件（例如 `.exe/.lnk/.reg`）用默认应用打开前也需要确认。

## 识别范围与回退

- 复用原生 Markdown 的 `a[data-local-link]` 及已验证存在的行内代码路径；不是遍历所有文本并把文件名强制变成链接。
- 每个 Markdown 容器绑定**自己的会话对象**。保留的旧时间轴不会因切换项目而使用另一个项目的目录。
- 相对路径严格按消息所属会话目录解析；不按文件名搜索并猜测结果。支持中文、空格、`file:` 地址和常见行号后缀。没有对应文件时明确报错。
- 远程服务器、SSH 隧道、远程 workspace 或本地身份不明确时，保留 OpenCode 原生行为，不触碰本机同名文件。不会仅凭 localhost 地址判断本地。
- Ctrl/Cmd/Alt/Shift 点击、普通网页链接、图片预览、代码块复制、没有本地路径的内存附件均不接管。
- 第一版覆盖主对话及继承原生 Markdown 会话上下文的 `/btw` 文件链接。**工具结果中已有的 Markdown 文件链接同样可用；原生 diff 标题、非 Markdown 文件卡片、仅有文件名的工具标题暂不额外接管**，避免覆盖展开 diff 等既有点击行为。
- macOS/Linux 提供打开、定位、复制路径；类型专属运行与目录终端暂只提供 Windows 版本。
- 已验证的接入版本为 2.4.1。旧版或未知版本的原生 Markdown 契约不匹配时，安装日志说明跳过本功能，不猜测压缩符号或阻断其他 Mod 功能。

## 实现与验证

- `file-actions.mjs`：只在原生 Markdown 容器监听事件，通过弱引用记录容器与所属会话，不改写 Markdown DOM 或文本。
- `file-actions-patch.mjs`：按已知原生契约注入会话来源；匹配必须唯一。
- `file-actions-preload.cjs`：仅暴露打开和右键菜单两个固定操作，不暴露通用 IPC 或任意命令执行。
- `file-actions-main.mjs`：主进程验证窗口来源、路径与文件状态，建立 Electron 原生菜单，处理确认和启动错误。
- `file-actions-core.mjs`：路径规范化、危险设备/网络路径拒绝和固定解释器参数。

主进程拒绝网络共享、Windows 设备路径、ADS、控制字符、非法盘符相对路径及危险的末尾点/空格；真实路径解析后再次检查。用户目录外的明确本地绝对路径允许访问，方便打开临时目录里的生成结果。脚本启动使用固定程序及参数，不把路径拼入任意 shell 命令；批处理通过固定环境变量单次展开传递路径，并禁用 CMD 自动运行配置和延迟展开。

```sh
npm run test:file-actions
npm test
node bundle.check.mjs --asar "官方 app.asar 副本路径"
```

测试包含路径/参数、来源会话、原生菜单、取消运行、IPC 来源校验、缺失文件及脚本类型限制。在 Windows 上只执行测试自身创建的无害 `.cmd` 文件，验证中文和特殊字符路径。ASAR 集成测试仅修改临时副本，覆盖打包、导入、校验和、重复安装和还原。**这些测试不替代重启真实桌面后的默认应用、资源管理器定位和运行窗口交互验收。**
