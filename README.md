# OpenCode Desktop Timeline & /btw Companion Mod

> 为 **OpenCode Desktop** (Electron 桌面端) 深度定制的增强套件：
> 1. **左侧极简时间轴导航条 (ChatGPT / Codex 风格悬浮游标)**：丝滑跳转任意轮次与小标题、支持跨长对话平滑减速滚动、内置本地持久化目录缓存与超长对话全量历史自动预加载。
> 2. **右侧升级版 `/btw` 多轮伴侣问答面板**：突破官方单轮与全量上下文限制，支持划词一键引用、独立模型切换、三档上下文范围控制、持久化多轮对话。

---

## 🌟 特性概览

### 1. 左侧会话时间轴导航条 (Timeline Scrubber)
- **极简隐形刻度尺**：借鉴 ChatGPT / Codex 悬浮时间轴，在主对话区左缘以极细水平刻线（`—`）呈现，不挤占对话宽度、不产生视觉干扰。
- **动态鱼眼波浪**：鼠标掠过时刻度线呈平滑高斯波浪展开，指引清晰自然。
- **懒加载悬浮预览卡片**：
  - 悬浮在刻度线上即时展示该轮提问序号、提问标题与内容摘要。
  - 自动解析该轮 AI 回答内的 Markdown `H1` / `H2` / `H3` 小标题目录并生成可点击树形跳转列表。
- **100% 丝滑减速滚动 (Cubic Ease-Out)**：
  - 针对 OpenCode 虚拟滚动列表（`@tanstack/virtual-core`）深度适配。
  - 直接提取虚拟列表底层像素偏移，彻底消除跨屏远距离跳转时原生虚拟列表强制瞬移闪烁或中途被打断的问题。
- **本地持久化缓存 + 自动预拉取超长历史**：
  - 打开超级长对话无需再手动向上拉滚动条触发分页。
  - 历史目录索引缓存至本地存储（`localStorage`），秒开秒出；后台静默调用 `loadMore({ all: true })` 补齐早期分页，平滑跳转任意早期历史轮次。

### 2. 右侧 `/btw` 伴侣问答面板 (Companion Chat)
官方原版 `/btw` 功能较为局限（每次问答都会强制捆绑发送当前主会话的完整历史、无法自由挑选模型、关闭即丢）。本增强补丁将其升级为完整的侧栏伴侣：
- **独立模型自由选择**：自动加载当前可用的模型列表，可随意选择高速便宜模型（如 MiniMax / DeepSeek / Claude 等）进行辅助问答，完全独立于主会话。
- **灵活的上下文控制**：
  - ⚡ **仅引用/当前**（默认）：不携带主会话历史，杜绝 Token 浪费与干扰，专注解答当前问题。
  - 🔗 **最近 3 轮**：注入最近几轮核心交互，理解上下文背景。
  - 📚 **完整主会话**：向模型提供主会话完整记录。
- **划词一键引用 / 解释**：
  - 在主对话区任意选中文字，弹出极简悬浮胶囊：`引用到 /btw` 或 `⚡ 解释`（快捷键：`Alt+Q`）。
- **持久化连续多轮对话**：
  - 底部完整多轮输入框，支持 `Shift+Enter` 换行、`Enter` 发送。
  - 面板关闭或重启客户端不丢失对话记录，并支持一键清空重置。
- **原生沉浸风格**：完全遵循 OpenCode v2 设计语言，原生主题自适应。

## 🚀 快速安装 (Windows)

### 前置要求
- 已安装并使用 **OpenCode Desktop (v2.0.32+)**
- 系统已安装 **Node.js** (v18+)

### 一键应用
1. 克隆或下载本仓库到本地任意目录：
   ```bash
   git clone https://github.com/Arihara-Satoru/opencode-desktop-mod.git
   cd opencode-desktop-mod
   ```
2. 双击运行 **`应用桌面端补丁.cmd`**（或在终端执行 `node apply-mod.mjs`）。
   - 脚本会自动检测你的 OpenCode 安装路径，并在首次执行时安全备份官方原版文件为 `app.asar.bak`。
3. 重启 OpenCode 桌面端窗口即可尽情体验！

## 🔄 还原官方原版

如果想随时彻底恢复官方原始界面：
- 双击运行 **`还原官方原版.cmd`**（或终端执行 `node apply-mod.mjs --restore`），然后重启 OpenCode 即可恢复如初。

## 🛠️ 技术原理与架构

本补丁采用**非破坏性追加式 ASAR 打包算法**与模块级增强：
- **零破坏 ASAR 注入**：保留 Electron `app.asar` 头部全部原有文件的对齐偏移不变，将修改后的 `main`、`route` 及全新独立模块 `panel-c7bWJg2T.js` 追加写入 Payload 尾部，更新索引表与 SHA-256 块校验和。升级或还原极其安全。
- **虚拟列表与平滑缓动协同**：
  - 拦截 OpenCode 的虚拟列表控制器 `__oc_timeline_ctrl` 与实例 `__oc_virtual_scroll`。
  - 在滚动开始前同步解除自动吸底锁定（`unpin()`），并前置刷新高度补偿状态（`be()`）。
  - 利用自相似三次缓动公式 `currentPos += (destTop - currentPos) * (1 - (remTime / duration)^3)` 实时追踪动态加载的 DOM 节点，保障全链路 60 FPS 平滑滚动。
